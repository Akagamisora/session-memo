# Changelog

## 0.2.0 - 2026-10-03

- 各メモに「送る」ボタンを追加。メモを自分の言葉として Claude に送り、ターンが始まったらそのメモを消す。Claude の作業中に押すと、手が空くまで「送信待ち」になる
- メモの件数をプロンプト下のステータス行に出す。0 件になったら消す

## 0.1.0 - 2026-10-03

- `/memo` でメモのペインを開く。入力欄に書いて Enter で追加、`x` で 1 件削除
- `/memo <文>` でペインを開かずに追記。`/memo list` / `save` / `clear`
- メモはセッション ID ごとに保存し、`/resume` で再開しても残る
- `~/claude-memos/<日付>-<セッション ID の先頭 8 文字>.md` への書き出し
